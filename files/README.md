# Сынак платформасы: катталуу жана кирүү

Flutter колдонмосу: каттоо жана кирүү экрандары, `flutter_bloc` аркылуу башкаруу.

## Валидация

- Аты, фамилиясы: кирилл тамгалары, эң аз 3 тамга
- Телефон: `+996` менен башталат
- Логин: латын кичине тамгалары, эң аз 3 тамга
- Сыр сөз: эң аз 8 элемент

## Запуск

1. Flutter проект түзүңүз: `flutter create exam_app`
2. `lib/main.dart` файлын ушул репозиторийдеги файл менен алмаштырыңыз
3. Пакетти кошуңуз: `flutter pub add flutter_bloc`
4. Иштетиңиз: `flutter run`
